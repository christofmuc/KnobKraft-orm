# The original KnobKraft introduction

Christof demonstrates the original patch librarian with a Sequential Prophet Rev2. The video shows **KnobKraft Orm 1.0.0**; its interface predates the lists and bank management added in version 2.

Use it for a look at the project and the basic idea of a computer library connected to a hardware synth. Follow the [written first-session lessons](index.md) for setup, import and storage distinctions in the current workflow.
