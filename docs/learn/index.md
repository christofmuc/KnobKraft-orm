# Your first session with KnobKraft

Start with one instrument and a small collection of sounds. These written lessons take you from a working connection to a shortlist you can find again.

| Step | What you will do | What you need |
| --- | --- | --- |
| 1. [Connect your synth](connect.md) | Set up MIDI and check the audio path | A supported synth, MIDI connection and audio monitoring |
| 2. [Know where your sounds live](library-and-hardware.md) | Tell a library patch from a hardware program | No hardware needed |
| 3. [Import a bank and keep a shortlist](import-a-bank.md) | Load a compatible file, organise a few sounds and back up the library | KnobKraft and a compatible patch file |

**Working without a synth?** Start at step 2, then import and organise files in step 3. The hardware makes the sound; importing a patch does not create an audio preview on the computer.

## Find a procedure

- [Browse and audition](../manual/04-browsing-and-auditioning.md): choose a send mode before clicking patches.
- [Search and categories](../manual/05-search-and-categories.md): find favourites and recover hidden sounds.
- [Lists and banks](../manual/06-lists-and-banks.md): prepare an arrangement for a specific instrument.
- [Export and backups](../manual/07-export-and-backups.md): preserve your library or make portable patch files.
